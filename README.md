# Turtle_first_experience
🐢 Turtle Experience

A small Python project created while learning and experimenting with the "turtle" library.

This project started as my first attempt to work with Turtle graphics. I gradually developed it by adding color patterns, customizable settings, random color orders, and user input.

✨ Features

- Draws geometric patterns using Python's "turtle" library
- Changes colors in a repeating rainbow-inspired pattern
- Allows the user to choose how many lines each color should have
- Allows the user to choose how many times the color pattern repeats
- Randomizes the order of the colors for each run
- Gradually increases the pen size while drawing

🛠️ Built With

- Python
- Turtle
- Random

📚 What I Learned

While working on this project, I practiced:

- "for" loops
- Lists and list indexing
- Variables
- Integer division ("//")
- Modulo ("%")
- User input with "input()"
- Type conversion with "int()"
- Using libraries with "import"
- Randomizing list elements with "random.shuffle()"
- Basic Turtle graphics

🚀 How to Run

Make sure Python is installed on your computer, then run:

python turtle_experience.py

The program will ask you how many lines each color should have and how many times the color pattern should repeat.

🌈 Project Evolution

This project began as a very simple experiment with Turtle graphics and gradually evolved into a more interactive program.

The original version was much simpler, but I decided to keep developing the idea instead of replacing it completely. Each version introduced a new programming concept and made the final result more customizable.

🎯 Purpose

The main purpose of this project was not to create a complex application, but to learn by experimenting and gradually improving a simple idea.
